# 对外文档快照

本目录是 `aeps-llm-wiki-plugin` 插件的**对外文档快照**,内容由 `src/` 下的源文档镜像而来。

## 同步策略

- **内部维护**(单一权威源):`<project>/src/prd.md` / `<project>/src/design.md` / `<project>/src/implement.md`
- **对外快照**(本目录):本目录下的对应三份文档
- **以 `src/` 为准**:若本目录与 `src/` 不一致,请以 `src/` 内的版本为权威,本目录仅作发布时镜像使用
- **同步时机**:每个对外发布版本号变更前,重新从 `src/` 复制一份到本目录(镜像脚本暂未落地,目前由维护者手工复制)

## 文档清单

| 文档 | 路径 | 作用 |
|---|---|---|
| **PRD** | [prd.md](prd.md) | 产品需求、用户故事、验收标准、非目标、风险 |
| **设计** | [design.md](design.md) | 模块边界、数据契约、关键流程、Obsidian 前端契约、钩子设计 |
| **实施** | [implement.md](implement.md) | 分阶段执行清单、阶段 A 骨架、阶段 B 五个技能、阶段 C 测试用例、阶段 D 发布、变更历史 |

## 内部维护与对外快照 的边界

- `src/` 下的文档是插件设计阶段的工作产物,会在迭代中持续更新,每个补丁版本号都会更新
- 本目录下的文档是给最终用户阅读的,只在发布前同步一次,**不带**频繁的设计期草稿痕迹
- `src/` 与本目录都包含变更历史章节,**不剥离**

## 同步时的注意事项

- 复制前请确认源文档已经在源文件所在位置通过了完整的设计阶段评审
- 复制后请检查本目录下三份文件的链接跳转是否仍然有效
- 复制过程中**不要**改动源文档任何内容,本目录只是镜像
- 若本目录与 `src/` 出现版本不一致的临时情况,请在变更历史章节记录原因

## 阅读路径建议

- **想用插件**:看根目录的 [README.md](../README.md)
- **想理解插件怎么设计的**:按需求 → 设计 → 实施顺序读
- **想二次开发**:看 `src/` 内的对应文档(与本目录内容一致,但路径引用等相对路径可能不同)
